## ⚙️ Overview

This tutorial provides a comprehensive walkthrough on creating a real-time chat application. It covers everything from setting up the React application and building the user interface to integrating Firebase for backend functionalities and finally deploying the application.

> 🛠️ I followed the video and built this project using the same structure. Toward the end, I copied much of Lama Dev's code into this repo. He explains Firebase with React well, but the frontend implementation has bugs and lacks proper validation or error handling.

## 🧰 Key Technologies and Concepts

### **Frontend (React)**

- React project setup and component structuring
- UI components: chat lists, messages, forms, avatars
- Styling and state management (using Zustand)

### **Backend (Firebase)**

- Firebase Authentication for user sign-up/login
- Firestore database for real-time chat syncing
- Firebase Storage for image uploads (avatars)

### **Deployment**

- Tutorial used Hostinger VPS setup
- I used **Firebase Hosting** instead for this version

### **Version Control**

- Git for commits and tracking
- GitHub for remote repo and GitHub Pages (potential CI/CD integration)
